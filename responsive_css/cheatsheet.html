📘 Responsive CSS Cheat Sheet

Quick reference for key Responsive Web Design concepts

🎨 Filters

CSS filters like grayscale(100%), blur(4px), and sepia(80%) adjust visual effects directly on images.

Example: img { filter: brightness(1.2); }

📱 Media Queries

Used to apply CSS rules depending on device width or orientation.

Example: @media (max-width: 600px) { body { font-size: 14px; } }

🌐 Responsive Design

Uses flexible layouts, images, and media queries to adapt to various screen sizes.

Example: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

🖋️ Typography

Use relative units and clamp() to make font sizes scalable.

Example: font-size: clamp(1rem, 2vw, 1.5rem);
