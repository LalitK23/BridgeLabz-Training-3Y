📦 Box-Sizing Comparison Page

This example compares two boxes: one using the default box-sizing (content-box) and the other using box-sizing: border-box;. Notice how padding and borders affect their total width differently.

Default: content-box

In the default model, padding and border are added to the element's total width and height.

Total size = content + padding + border

box-sizing: border-box;

With border-box, padding and border are included within the defined width and height.

Total size = fixed width (no growth from padding)
